# safe-by-design

A game framework and curriculum for teaching digital literacy to kids aged 8-14.
Think Oregon Trail energy — but the wagon is your privacy settings.

## Status
Coming Soon — RFC open, contributions welcome

## Vision
- Browser-based game engine built for classroom and home use
- Curriculum modules: privacy, stranger danger, password safety, consent
- Teacher/parent dashboard with progress tracking
- Fully offline-capable

## Get Involved
This repo is in RFC stage. Open an issue to propose a game mechanic,
curriculum module, or technical approach.
